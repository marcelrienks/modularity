# Multiboard Custom Tool Hangers

Custom 3D-printed tool organizers extending the **Multiboard** modular pegboard system.

## About Multiboard

Multiboard is an open-source, modular 3D-printing system for workshop organization. It features a grid of holes compatible with hundreds of interchangeable hooks, holders, and organizers that can be easily 3D printed and customized. With its community-driven ecosystem and extensive library of accessories, Multiboard enables infinite customization for any workspace.

**Official Source:** [multiboard.io](https://www.multiboard.io/)

## Custom Tool Hangers

This directory contains custom tool hanger designs created to extend the Multiboard system with specialized storage for various hand tools.

### Models

| Model | Purpose | Files |
|-------|---------|-------|
| **Long Hammer** | Hang and organize large hammers | `Long Hammer R1.stl` / `.step` |
| **Small Hammer Peg** | Mount small hammers to pegs | `Small Hammer Peg R1.stl` / `.step` |
| **Plier Rack** | Organize and display multiple pliers | `Plier Rack R1.stl` / `.step` |
| **Screwdriver Hanger** | Hold screwdrivers upright or angled | `Skrewdriver Hanger R1.stl` / `.step` |
| **Socket Hanger** | Organize and access socket sets | `Socket Hanger R1.stl` / `.step` |
| **Spanner Hanger** | Store and display wrenches/spanners | `Spanner Hanger R3.stl` / `.step` |

## File Formats

- **STL files** - Ready for 3D printing (recommended for FDM printers)
- **STEP files** - CAD-native format for design modification and further customization

## 3D Printing

Each model is available in both STL and STEP formats, allowing you to:
- Print directly as-is (STL)
- Modify dimensions and features (STEP)
- Re-export to any format your printer requires

### Recommended Materials

- **PETG** - Best for strength and durability
- **ABS** - Excellent for load-bearing applications
- **PLA** - Fine for lighter-duty hangers

## Integration with Multiboard

These custom hangers are designed to integrate seamlessly with the Multiboard system:
- Compatible with standard Multiboard mounting points
- Can be combined with official Multiboard accessories
- Designed to work with M5 hardware and Multiboard's modular grid

## Usage

1. Download the STL file for your desired tool hanger
2. Load into your slicing software
3. Print with appropriate settings for your material choice
4. Mount to your Multiboard pegboard system
5. Organize your tools!
